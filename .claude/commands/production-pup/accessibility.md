# Production Pup: Accessibility

Run the accessibility-focused Production Pup audit.

Read `SKILL.md` first and use its Accessibility section as the source of truth.

## Command

`/production-pup/accessibility`

Audit and, when requested, fix:

- keyboard navigation
- visible focus states
- color contrast
- semantic HTML
- accessible labels
- meaningful button and link names
- correct link semantics
- useful alt text
- decorative-image handling
- reduced-motion support
- touch targets
- readable text and line length
- useful validation errors
- state communication without color alone
- skip-to-content navigation
- mobile accessibility
- icon-only controls

Test actual interaction paths rather than relying only on static markup inspection.
