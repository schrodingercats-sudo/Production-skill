# Production Pup: SEO

Run the SEO and discoverability-focused Production Pup audit.

Read `SKILL.md` first and use its SEO and Discoverability section as the source of truth.

## Command

`/seo`

Audit and, when requested, fix:

- unique page titles
- useful page-specific meta descriptions
- clear H1 and heading hierarchy
- canonical URLs
- clean URL slugs
- sitemap.xml
- robots.txt
- structured data / schema.org
- Open Graph and social preview metadata
- OG images
- favicon and app icons
- custom 404 pages
- internal links and broken links
- alt text
- HTML `lang`
- production source maps
- console and network errors affecting indexing or UX
- unnecessary starter/framework traces
- Core Web Vitals and crawl-impacting performance issues
- `llms.txt` when useful for the project's AI discoverability strategy

Do not fabricate reviews, ratings, customer counts, structured-data claims, or other SEO content.

Arguments: $ARGUMENTS
